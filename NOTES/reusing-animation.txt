we can reuse the repetative animation using animation method

const translateStyle = animation([
  style({
    opacity: 0,
    transform: 'translateX(-100%)',
  })
]);

export const staggeredListAnimation = trigger('staggeredListTrigger', [
  transition('* => *', [
    query(
      ':enter',
      [
        useAnimation(translateStyle)
        stagger(200, [
          animate(
            '800ms ease-out',
            keyframes([
              style({
                opacity: 1,
                transform: 'translateX(10%)',
                offset: 0.4,
              }),
              style({
                opacity: 1,
                transform: `translateX(0)`,
                offset: 1,
              }),
            ])
          ),
        ]),
      ],
      { optional: true }
    ),
  ]),
]);


we  need to define all styles in animation method
If we have multiple animation, then it should be declared inside an array

and to use this animation, we need to make use of useAnimation method

apart from this we can pass value in the form of params

const translateStyle = animation([
  style({
     opacity: '{{opacity}}',
    transform: '{{transform}}',
  })
], {params: {opacity: 0, transform: 'translateX(-100%)'}});

and when using useAnimation, we need to send this params as well
..
 useAnimation(translateStyle, {params: {opacity: 0, transform: 'translateX(-100%)'}}),
 ..

 we can also pass this params from the component level also

const translateStyle = animation([
  style({
     opacity: '{{opacity}}',
    transform: '{{transform}}',
  })
], {params: {opacity: 0, transform: 'translateX(-100%)'}});

export const staggeredListAnimation = (params) => trigger('staggeredListTrigger', [
  transition('* => *', [
    query(
      ':enter',
      [
        useAnimation(translateStyle, {params: params}),
        stagger(200, [
          animate(
            '800ms ease-out',
            keyframes([
              style({
                opacity: 1,
                transform: 'translateX(10%)',
                offset: 0.4,
              }),
              style({
                opacity: 1,
                transform: `translateX(0)`,
                offset: 1,
              }),
            ])
          ),
        ]),
      ],
      { optional: true }
    ),
  ]),
]);

in the component file
..
animations: [staggeredListAnimation({opacity: 0, transform: 'translateX(-100%)'})]
