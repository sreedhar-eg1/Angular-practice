Staggered List using Angular Animations

there will be lifecycle hooks in angular Animations

whenever animation occurs, it goes through two phase
that is when the animation start, and when the animation ends

(@courseAddTrigger.start)="onAnimationStart($event)"
(@courseAddTrigger.done)="onAnimationEnd($event)"

we can make use of this like event binding

onAnimationStart(event: AnimationEvent) {
}

in angular there ia an staggered option, with the help of this we can add staggered animation

 transition('* => *', [
    query(':enter', [
      stagger(200, [animate(
        '800ms ease-out',
        keyframes([
          style({
            opacity: 0,
            transform: 'translateX(-100%)',
            offset: 0,
          }),
          style({
            opacity: 1,
            transform: 'translateX(10%)',
            offset: 0.4,
          }),
          style({
            opacity: 1,
            transform: `translateX(0)`,
            offset: 1,
          }),
        ])
      ),])
    ], { optional: true }),
  ]),

we can use stagger only with the combination of query
