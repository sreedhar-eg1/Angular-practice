Shadow DOM
It will hide the DOM logic behind the elements and also scope the styles to an element

if we specify shadowDOM using encapsulation: ViewEncapsulation.shadowDOM, then the global syles specified in the styles.css
will not be applied, only the styles that is scoped to that component will be applied

The difference between emulated and shadowDOM is, global styles wont work in shadowDOM whereas it will work well with angulars default emulated approach

If we want to apply style to the component in the component declaration, then we can use :host
if we want to apply using any selector then we can use :host(selector_name)
here host element means component name

If we want to apply style to the parent element of the host element, then we can use :host-context(parent_selector(class,id..))
here style will be applied to the host element, not the parent element

In a component, if we use another component, and then we need to apply style for that component in the component where it has been used
then we need to use ::ng-deep, this is deprecated
we can use /deep/ instead of ::ng-deep, this is also deprecated
or we can use >>> instead of ::ng-deep, here basically this is deprecated
any style that is applied using ::ng-deep will become global styles

NgClass directive
we can use ngClass to dynamically add and remove classes
we can pass string , array, object to ngClass directive
string -> [NgClass]="'active'"
array -> [NgClass]="['active', 'class-1]"
object -> [NgClass]="{active: true, 'class-1': true}"

to remove or add single class we can use class binding
[class.active]="isActive"
so with class binding we can use array and object as well
[class]="["a", "b"]"

NgStyle
If we need to add style element, then we can make use of NgStyle
here ngStyle value is an javascript object, where key is css property, and value is its value
in place of value we can use function, which in turn return the value of the css property
If we have single style to apply then we can make use of [style.backgroundColor]="red"
we can add pixel in alternative way using [ngStyle]="{'fontSize.px': 24}"
